# Recording and upload checklist

## Before recording

- [ ] Restore network access; verify official OpenAPI, schemas, timestamp semantics and real January responses.
- [ ] Acquire January data; inspect quality/coverage and retained vintages. Do not imply completeness from multiple vintages alone.
- [ ] Install frontend dependencies, generate/commit lockfile, run frontend tests and production build.
- [ ] Run backend tests, Docker startup and representative browser journeys.
- [ ] Verify deployed frontend/backend URLs, cross-origin requests and snapshot freshness.
- [ ] Confirm repository is public and anonymous; scan files and Git history for secrets and personal identifiers.
- [ ] Prepare one covered date and interval; record actual publication, forecast, actual and hand-checkable error values in private rehearsal notes.
- [ ] Close account menus, terminals with personal paths, environment files, tokens, notifications and unrelated tabs.
- [ ] Set a readable desktop viewport, check contrast/zoom, microphone and screen capture.
- [ ] Rehearse both parts in 9:30; allow at most 10:00 total.

## Record

Use OBS Studio or the operating system recorder. Record screen and narration to one local file. Follow `demo-script.md`; use `technical-walkthrough.md` for code navigation. Do not claim an unverified URL, test, data result or measured benefit. If data remains unavailable, disclose it rather than replacing observations with synthetic fixtures.

## Review and upload

1. Watch the full recording, check audio and remove any exposed private material.
2. Check total duration is ≤10:00 with both client and technical sections included.
3. Sign in to the intended YouTube account, open YouTube Studio → Create → Upload videos.
4. Upload the reviewed file. Use the neutral title “WindMarket Intelligence — Product and Technical Review”.
5. Add source acknowledgements and verified repository/deployment links only. Set audience appropriately and visibility to **Unlisted**.
6. Complete processing, open the link in a signed-out/private window and confirm playback.
7. Add the verified URL and duration to the submission record. No upload is currently completed.
